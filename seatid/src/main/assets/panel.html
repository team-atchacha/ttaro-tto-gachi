여기서 누르면 에뮬레이터 화면이 바뀝니다. 차 화면의 질문은 에뮬레이터에서 직접 눌러도 되고, 아래 "탑승자 응답"으로 대신 눌러도 됩니다.

SDK Virtual Console → 차량 속성 → Vehicle SDK 구독으로 앱에 전달 (실제 경로) 시뮬레이션 에뮬레이터가 값을 못 줘서 앱에 직접 넣는 값 (실차에서는 SDK가 줌)

시나리오

순서대로 눌러 보면 "운전자 자동 인식 → 동승자 추천 확인 → 짐 구분 → 하차"가 이어집니다.

운전자 = 차 화면에 로그인된 차량 사용자 프로필 Android

운전자를 바꾸려면 에뮬레이터 화면 맨 위의 프로필 아이콘(동그라미)을 눌러 아빠·엄마·운전자 중에서 고르고, 바뀐 프로필에서 "탑승자 인식 데모" 앱을 다시 여세요. 이 페이지는 몇 초 뒤 새 사용자의 앱에 다시 연결됩니다. 프로필마다 처음 한 번은 운전석에 앉을 때 누구인지 묻고, 그다음부터는 묻지 않습니다. (일반 앱은 프로필 이름을 읽을 수 없어서 주인을 한 번 정하는 방식입니다.)
